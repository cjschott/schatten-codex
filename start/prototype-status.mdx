The current SCHATTEN prototype is built to validate combat decisions and the clarity of the player experience. It is not a finished character progression game.

| Capability | Status | Notes |
| --- | --- | --- |
| Browser duels against AI | **Playable** | Four available opponent strategies |
| Four equipment-defined loadouts | **Playable** | Preconfigured, validated 22-card decks |
| Manifest and Veil casting | **Playable** | Includes fuse, reaction, and slot mechanics |
| Deterministic duel records | **Playable** | Export, import and verified step-by-step review |
| Wizard's Journal | **Playable** | Browser-local notes; not synchronized across devices |
| Feedback submission | **Playable** | Authorized hosted testers |
| Player-earned gear and inventory | **Planned** | No progression rewards in this prototype |
| Crafting or upgrading gear | **Planned** | No upgrade loop in this prototype |
| Saveable custom equipment builds | **Planned** | Prototype uses fixed validated presets |
| Complete searchable card encyclopedia | **Planned** | Existing cards are shown with loadouts |
| AI coaching and verified alternative actions | **Planned** | Export is not an AI explanation |
| Cinematic battle replay | **Planned** | Distinct from the present tactical record viewer |
| Full wizard appearance customization | **Planned** | Character workstream is incomplete |

## What to evaluate

The playtest asks whether combat is satisfying and understandable: can you follow card effects, distinguish Manifest from Veil, understand mana and carry, and make interesting choices under pressure?

Winning or losing a single match does not establish balance. Repeated observations, especially those linked to a replay step, are more useful.

See the [playtest feedback handbook](/playtest/feedback).
