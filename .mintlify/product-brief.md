# SCHATTEN Codex product brief

## Description
Player-facing living documentation for SCHATTEN, a wizard card battler where equipment determines the deck. The current browser prototype tests deterministic combat and AI opponents.

## Primary audience
Authorized prototype testers first, and future players who want a searchable rules reference and gear/card encyclopedia.

## Jobs to be done
1. Start a match and understand its turn decisions.
2. Learn current rules, preset equipment and cards.
3. Replay/export a duel and make useful, reproducible feedback reports.

## Motivation
Make strategic depth approachable and expose confusing mechanics before investing in progression, art and cinematic layers.

## Assumptions and constraints
- The Codex site is planned as publicly readable. The game remains restricted.
- Contents are anchored to web a84f128c5017 and rules-core 0.4.0, and must be updated when those change.
- Future card and item encyclopedia entries must derive from canonical validated content.
- This documentation repository does not replace or edit the existing Mintlify Virryn project.
